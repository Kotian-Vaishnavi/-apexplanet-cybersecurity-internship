# Task 5: Web Application Penetration Testing
## Day 49: Planning & Setup

### What is this project?
I will hack a practice website called DVWA and write a professional security report.

### The Website
- Name: DVWA (Damn Vulnerable Web Application)
- URL: http://localhost/dvwa/
- Purpose: A practice target for learning hacking
- Login: admin / password

### What I'll Find
I will look for security holes (vulnerabilities) in this website and:
1. Find the hole
2. Exploit it (hack it)
3. Take a screenshot as proof
4. Write down what I found
5. Explain how to fix it
