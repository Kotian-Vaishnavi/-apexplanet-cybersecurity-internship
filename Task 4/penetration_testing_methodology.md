## The 5 Phases of Penetration Testing

### Phase 1: Reconnaissance (Information Gathering)
**Goal:** Gather as much information about the target as possible
**Activities:**
- Identify IP addresses
- Discover open ports
- Identify services and versions
- Map network topology
**Tools:** Nmap, Whois, Google Dorking

---

### Phase 2: Scanning (Vulnerability Assessment)
**Goal:** Identify vulnerabilities that can be exploited
**Activities:**
- Port scanning
- Service enumeration
- Vulnerability scanning
**Tools:** Nmap, OpenVAS, Nessus, Nikto

---

### Phase 3: Exploitation (Gaining Access)
**Goal:** Exploit vulnerabilities to gain access to the system
**Activities:**
- Selecting appropriate exploits
- Executing exploits
- Gaining initial access
**Tools:** Metasploit, manual exploits, SQLMap

---

### Phase 4: Post-Exploitation (Maintaining Access)
**Goal:** Expand access and gather valuable information
**Activities:**
- Privilege escalation
- Credential harvesting
- Installing backdoors
- Data exfiltration
**Tools:** Meterpreter, privilege escalation scripts

---

### Phase 5: Reporting
**Goal:** Document all findings professionally
**Activities:**
- Executive summary
- Detailed findings
- Evidence (screenshots)
- Remediation recommendations
